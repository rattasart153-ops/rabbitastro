# 00 — ภาพรวมโครงการ Rabbitastro

## 1. วัตถุประสงค์

Rabbitastro เป็นเว็บไซต์ที่รวมเครื่องมือคำนวณและเนื้อหาพยากรณ์ตามชุดกฎเฉพาะของโครงการ โดย Source Code ที่ตรวจสอบเป็นเว็บแอปพลิเคชัน HTML ซึ่งรวมโครงสร้างหน้าเว็บ รูปแบบการแสดงผล JavaScript และชุดข้อมูลคำทำนายไว้ในไฟล์หลัก

เอกสารนี้เป็นจุดเริ่มต้นสำหรับทำความเข้าใจขอบเขตระบบและแนวทางพัฒนา ไม่ใช่ข้อกำหนดผลิตภัณฑ์ที่ผู้ใช้ยืนยันครบถ้วนแล้ว

## 2. เป้าหมายการพัฒนา

- รักษาความสามารถเดิมของเว็บไซต์
- ทำความเข้าใจสูตรคำนวณและกฎการเลือกคำทำนายก่อนเปลี่ยนแปลง
- แยกเอกสารความต้องการ สูตร ข้อมูล และรายละเอียดทางเทคนิคให้อ่านตรวจสอบได้
- ใช้ Markdown เป็นแหล่งข้อมูลหลักในการออกแบบและติดตามการพัฒนา
- เพิ่มการทดสอบที่ทำซ้ำได้และบันทึกหลักฐานทุกครั้ง
- พัฒนาการเปลี่ยนแปลงใน Branch ทดลองโดยไม่กระทบ Branch ต้นฉบับ

## 3. ขอบเขตฟังก์ชันที่ตรวจพบ

จากการอ่าน Source Code พบแท็บ/ส่วนการทำงานหลัก 4 ส่วน:

1. ดวงบุคคล
2. เทพประจำตัว
3. โอเรกุรัม
4. ไพ่ทาโรต์และรูน

มีข้อมูลและตรรกะที่เกี่ยวข้องกับเลขศาสตร์ พื้นดวง ลัคนาตามอัลกอริทึมของระบบ กระต่าย/ธาตุ พลังประจำวัน คำทำนายรายหัวข้อ ราย 7 วัน ราย 3 เดือน ไพ่ รูน และคริสตัล

รายการนี้เป็นขอบเขตที่ตรวจพบใน Source Code ไม่ใช่การรับรองความถูกต้องทางโหราศาสตร์หรือการยืนยัน UX ทุกเส้นทาง

## 5. หลักการตัดสินใจ

- Source Code ปัจจุบันเป็นหลักฐานของพฤติกรรมที่มีอยู่
- เอกสาร Specification ระบุพฤติกรรมที่เข้าใจจาก Source Code และต้องติดป้ายส่วนที่ยังไม่ยืนยัน
- การเปลี่ยนแปลงสูตรหรือคำทำนายถือเป็นการเปลี่ยนพฤติกรรมสำคัญ ต้องได้รับการตรวจสอบก่อน
- การแก้บั๊กต้องมีตัวอย่างก่อน/หลังและ Regression Test
- การปรับ UI ต้องไม่ทำให้ข้อมูลที่ผู้ใช้กรอกหรือผลลัพธ์เดิมสูญหายโดยไม่ตั้งใจ

## 6. สิ่งที่ยังไม่ยืนยัน

- พฤติกรรมขณะใช้งานจริงบน Browser และอุปกรณ์หลายขนาด
- ความถูกต้องของทุกสูตรและทุกข้อความคำทำนาย
- ความปลอดภัยของข้อมูลเมื่อใช้งานจริง
- ความจำเป็นและรูปแบบของ Backend/API ในอนาคต
- ข้อกำหนดด้านการสำรอง/กู้คืนข้อมูลและการเก็บรักษาข้อมูลส่วนบุคคล
