## Non-content calculation and selection code — explicitly excluded

The following must remain in JavaScript: arithmetic/reduction functions; Thai/English numerology mappings; date/time and ascendant calculations; question scoring; bucket selection; tarot/rune/card selection; result-number generation; generated RHD matrix construction and synthesis; and all engine routing/lookup algorithms.

## Destination collections

- `Predictions`: authored interpretation payloads, profiles, deity meanings, card/rune/crystal meanings and advice.
- `Categories`: category labels and descriptions.
- `Topics`: topic definitions, prompts and topic-level descriptive content.
- `Variables`: descriptive reference data only where it is genuinely used as runtime content; never formula constants.
- `Features`: display metadata and engine/feature labels.
- `Rules` and `Mappings`: only if an existing authored conditional mapping can be represented without changing its meaning. Do not invent new rules to force-fit legacy logic.
