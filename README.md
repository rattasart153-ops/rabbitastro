## กติกาการพัฒนา

- ทำงานและ Commit เฉพาะ Branch `rabbitastro-sandbox` เว้นแต่ได้รับคำสั่งเปลี่ยนแปลง
- ห้ามแก้ไข `index` และ `main` โดยไม่มีคำสั่งอนุญาตชัดเจน
- ห้ามลบหรือเปลี่ยนพฤติกรรมเดิมโดยไม่มีการบันทึกผลกระทบและได้รับอนุมัติ
- ทุกการเปลี่ยนแปลงต้องอัปเดตเอกสารที่เกี่ยวข้องและ `docs/CHANGELOG.md`
- แยกข้อเท็จจริงจาก Source Code, ข้อสันนิษฐาน และผลทดสอบจริงให้ชัดเจน
- ห้ามระบุว่า Test ผ่าน หากยังไม่ได้รันทดสอบและบันทึกหลักฐาน
- ก่อนแก้ไข Source Code ให้ระบุไฟล์/ฟังก์ชันที่เกี่ยวข้อง แผนแก้ไข และผลกระทบที่คาดไว้
